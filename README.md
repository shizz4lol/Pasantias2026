# Santuario de Letras

Este proyecto es una plataforma web de gestión literaria diseñada para organizar colecciones de libros. Ofrece una interfaz intuitiva desarrollada con PHP Nativo (POO), MySQL y Bootstrap 5 con un diseño personalizado oscuro y dorado.

## Características Principales
-Registro: Es la pantalla inicial del sistema para crear una cuenta nueva. Si ya tenés una, hay un botón que te lleva directo al Login.

-Login: Pantalla para ingresar introduciendo los datos de tu cuenta de forma segura.

-Cerrar sesión: Un botón en el encabezado para salir de la cuenta de forma segura.

-Ver los libros: Una pantalla principal con una tabla que muestra el Nombre, Autor e ISBN de los libros guardados.

-Agregar libros: Un formulario sencillo para cargar nuevos ejemplares a la lista de la librería.

-Modificar y Eliminar: Permite cambiar algún dato de un libro que ya estaba cargado mediante un formulario de edición, o directamente borrarlo de la tabla.

## Cómo hacerlo funcionar en tu computadora
1-Copiar los archivos: Poné la carpeta del proyecto adentro de htdocs si usás XAMPP.

2-Preparar la base de datos: Entrá a phpMyAdmin, creá una base de datos nueva llamada bd_biblioteca e importá el archivo db.sql.

3-Poner la foto de fondo: Guardá tu imagen de fondo en la carpeta principal del proyecto con el nombre exacto Fondo_Página.jpg .

4-Abrir la página: Entrá desde el navegador a http://localhost:8000/ para empezar a usarla.
